# MLX90614 — Passive IR thermometer

I2C address **0x5A**. Non-contact object temperature (and ambient). Prefer ~100 kHz I2C.

## Connect and read

```python
from eyes17 import eyes
from eyes17.SENSORS import MLX90614

p = eyes.open()
pir = MLX90614.connect(p.I2C)
print(pir.getRaw())                    # [object_temp_C]
print(pir.getObjectTemperature())
print(pir.getAmbientTemperature())
```

## Source select

```python
pir.select_source('object temperature')   # default
pir.select_source('ambient temperature')
print(pir.getRaw())
```

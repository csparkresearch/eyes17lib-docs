# BH1750 — Ambient light (lux)

I2C address **0x23**. Class name in code is `BRIDGE`; import the module as usual.

```python
from eyes17 import eyes
from eyes17.SENSORS import BH1750

p = eyes.open()
lux = BH1750.connect(p.I2C)
print(lux.getRaw())   # [lux]
lux.setRange('1000mLx')  # '500mLx', '1000mLx', '4000mLx'
```
